Atom Material Icons for Eclipse

Eclipse update site · version @VERSION@

Material Design file and folder icons for the Project Explorer, ported from the Atom Material Icons plug-in for IntelliJ.

Install

  1. In Eclipse, open Help › Install New Software…
  2. Paste this address into Work with and press Enter: https://socra167.github.io/eclipse-atom-material-icons/
  3. Select Atom Material Icons, finish the wizard and restart Eclipse.

Requires Eclipse 2024-03 or newer and Java 17.
