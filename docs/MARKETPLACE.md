## Long description

> Atom Material Icons brings the Material Design file and folder icons of the popular IntelliJ
> plug-in to the Eclipse Project Explorer.
>
> - 1,700+ file icons and 350+ folder icons, chosen by file name, extension and folder name with
>   the same rules as Atom Material Icons
> - Java files show the type they declare: class, abstract class, interface, enum, record,
>   annotation, exception or test class
> - Clear error and warning overlays, configurable separately; Git and other decorations keep
>   working
> - Crisp on HiDPI screens
> - Preferences under *General › Appearance › Atom Material Icons*, including optional icon packs
>   (Angular, NestJS, Redux, Rails, ...)
>
